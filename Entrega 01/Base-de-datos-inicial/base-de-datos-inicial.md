# Base de datos inicial
Nuestra base de datos será construida a partir de los datos recogidos de los siguientes sitios web y repositorios oficiales:
- Olympedia/Sports-Reference
- Comité Olímpico Intercional (Sitio oficial y API de París 2024)
- World Bank Open Data
- Medios de comunicación Internacionales y de periodismo de datos como **The New York Times (The Upshot) y BBC Data Team**

A partir de esta recolección, los datos serán clasificados por año de los Juegos Olímpicos, disciplina deportiva, número de competidores masculinos y femeninos, porcentaje por género, brecha porcentual y pruebas medallables disponibles. Cada clasificación corresponderá a una columna en nuestros archivos CSV. De esta manera, utilizaremos tanto la descarga directa de datasets consolidados como el método de **web scraping** para la construcción de nuestra base de datos.
En el caso **The New York Times** (https://www.nytimes.com/) y **BBC Data Team** (https://www.bbc.com/), al ser medios de comunicación internacionales, realizaremos una recolección manual de artículos e investigaciones sobre equidad de género que no sean útiles. Los propietarios son las empresas The New York Times Company y la British Broadcasting Corporation (BBC). Sus autores, por lo tanto, serán los periodistas de datos o críticos deportivos que hayan escrito las piezas seleccionadas. Contienen datos clave como contexto histórico, análisis de transmisión televisiva y comparativas de atletas femeninas en distintas ediciones. 
Gracias a **Olympedia/Sports-Reference** (https://www.olympedia.org/), respaldado por la Sociedad Internacional de Historiadores Olímpicos (ISOH), obtendremos la base de datos histórica con los registros individuales de atletas desde París 1900 hasta Río 2016. Esta fuente nos brindará variables como el nombre del atleta, sexo, país (NOC), disciplina, evento disputado y medallas obtenidas, sirviendo de línea base para medir la evolución histórica. 
El **Comité Olímpico Internacional (COI)** (https://olympics.com/), a través de su portal oficial y la API de París 2024, nos propicia el seguimiento de los cupos oficiales asignados por disciplina, la grilla de pruebas con opción a medalla y la composición definitiva de atletas (5.250 hombres y 5.250 mujeres) de la última cita olímpica. 
**World Bank Open Data** (https://data.worldbank.org/), del Grupo Banco Mundial, nos otorgará datos públicos sobre el Producto Interno Bruto (PIB) per cápita y regiones geográficas de cada país participante. Esto nos servirá para cruzar la procedencia de las delegaciones con el porcentaje de atletas femeninas que envían a los Juegos.
La metodología mediante la cual levantamos los datos es **OSINT** (Inteligencia de Fuentes Abiertas). Esto debido a que decidimos usar información pública -registros olímpicos, cuotas de cupos, censos de atletas y datos macroeconómicos- para esta forma verificar, conectar, limpiar y contrastar los datos entre las distintas fuentes.
