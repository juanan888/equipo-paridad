*Esta página fue creada con la crónica anterior, sin correcciones, al no recibir correcciones de la Entrega 03 todavía. 

Comencé el sitio web creando un nuevo repositorio llamado "primera-pagina". Luego cree una carpeta llamada "docs" que contiene un archivo "index.html", desarrollado con Visual Studio Code. Este nombre de archivo permite que los servidores web lo identifiquen automáticamente como la página de inicio o página principal del sitio. 

Como ya habíamos trabajado en algunos elementos de la estructura de la página durante la clase, utilicé como base el código existente. Empecé incorporando el contenido, como el material era el de la crónica elaborada para la "Entrega 03", el proceso resultó fácil. 

Comencé insertando el primer párrafo en su sección correspondiente. Luego, decidí incorporar el gráfico entre el primer y el segundo bloque de texto, para una mejor comprensión de la lectura. Para lograrlo, volví nuevamente a la Entrega 03, copié el código del gráfico y lo pegué directamente en Visual Studio entre estos dos párrafos. 

Una vez integrado el gráfico, procedí a completar las secciones siguientes. Para concluir, añadí una imagen de la incorporación de las primeras mujeres al Comité Olímpico Internacional (COI) durante la presidencia de Juan Antonio Samaranch. Para ello busqué en internet imágenes sobre este acontecimiento histórico y seleccioné una imagen que representara el hito de la manera más adecuada. Copié la dirección de la imagen para insertarla mediante la etiqueta HTML correspondiente y añadí un enlace a la fuente original utilizando una etiqueta de anclaje para otorgar el crédito pertinente.

Finalmente, optimicé la estructura del documento organizando el contenido en secciones con sus respectivos subtítulos y le coloqué el título a la página. Luego guardé todo, y revisé cómo estaba quedando la página, para terminar observándola en línea a través del link de Github pages.
